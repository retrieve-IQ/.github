## Getting Started

### For End Users
1. Read the [README.md](../README.md) for an overview
2. Check the [FAQ](./FAQ.md) for common questions
3. Use the [Troubleshooting](./TROUBLESHOOTING.md) guide if issues arise

### For Developers
1. Review the [API Reference](./API.md) to understand endpoints
2. See [Examples](./EXAMPLES.md) for code samples in your preferred language
3. Check [Best Practices](./BEST_PRACTICES.md) for optimization tips
4. Read [Architecture](./ARCHITECTURE.md) if deploying custom solutions

### For Operations Teams
1. Study the [Architecture](./ARCHITECTURE.md) deployment guides
2. Review [SECURITY.md](../SECURITY.md) for security best practices
3. Check monitoring and alerting documentation in internal docs

## Contributing to Documentation

To improve this documentation:

1. **Typo/grammar fixes**: Submit a PR with your changes
2. **New sections**: Create an issue first to discuss structure
3. **Code examples**: Ensure they're up-to-date with current API versions
4. **Translation**: We're open to community translations (contact docs@retrieve-iq.com)

## Versioning

Documentation is versioned alongside the API:

- Current stable: v2.x → See [CHANGELOG](../CHANGELOG.md)
- Beta features: Marked as `[Beta]` in headers
- Deprecated: Documented with removal timeline
